# PHASE1_INTEGRITY_PLAN — Phase1 완성(정합성) 테스트 프레임

> 목적: Phase1이 쏟아낸 데이터를 **감사 대상처럼 해부**해 Phase2로 넘길 자격이 있는지 판단한다.
> "에러 없이 돌았다"가 완성이 아니다. 아래 A~F를 측정하고, **에이전트(LLM)가 출력을 직접 읽고**
> 케이스별로 판단한다. 1급 대상 = 백테스트 분식 5사. 작성 2026-06-09(돌리기 전 합의된 프레임).

## 실행 방식

- 정합성 감사 하니스 1개로 A~F를 측정 → `data/backtest/`에 산출.
- 대상 = 분식 5사(두산에너빌리티·아스트·디아이동일·모델솔루션·셀트리온) + 20개 테스트사.
- 측정값을 LLM(작업 에이전트)이 읽고 "이 회사 데이터가 Phase2에 넘길 만한가"를 판단·리포트.
- **우선순위**: 존재론적 3개(정정공시·금액가중·provenance)부터.

## A. 완전성 — "DART가 준 걸 다 담았나" (거시→미시)

- 수집 퍼널: raw DART 행 → validated → mapped → dedup → 최종. **단계별 손실량·사유**(진짜 중복 제거 vs 실계정 소실).
- **연도 연속성**: 회사별 상장~최신까지 구멍 없나, 분식연도 포함됐나(DART API 불필요, 우리 데이터로 측정).
- **수집 실패 구멍**: 조용히 빠진 회사연도(로그 대조).
- 5표(BS/IS/CIS/CF/SCE)·CFS/OFS 누락 회사.
- (옵션) 분식 5사 한정 **DART 직접 대조** — DART 보유 vs 우리 보유.

## B. 숫자 정합성 — 회계 항등식

- 자산총계 = 부채총계 + 자본총계 (round 후, materiality 내).
- 유동+비유동 = 총계 (자산·부채 각각).
- 당기순이익 표간 일치 (IS/CIS/SCE/CF 같은 순이익인가).
- SCE: 기초자본 + 변동 = 기말자본 (D-D 2D 합계검증).
- 시계열: 올해 prior_amount = 작년 amount (인접연도 연결).

## C. 분류 품질 — 매핑·쏠림

- 매핑 신뢰도 분포: exact_taxonomy / alias / unmapped(기타) 비율, 기타 과도 회사.
- **이질병합 회귀**: 한 canonical에 statement 불일치·이질 account_id 혼입(D-B/C/A 등록 부작용).
- **금액가중 미분류**: 행수 아닌 **금액(materiality) 기준 미분류율** — 큰 계정이 기타로 빠졌나.
- **소계 이중계상**: 소계(유동자산계)와 구성(현금·채권)이 둘 다 있어 집계 시 2배. is_subtotal 일관성.
- 회사 간 비교가능성: 같은 경제실질이 회사마다 같은 canonical로 가나.

## D. 차원 정합성

- 통화/스케일: USD/KRW 혼재·천원↔원 1000배 점프(D-F 가드 실효).
- 부호 일관성: 비용·차감·제거 항목 부호.
- 이상치: source-scale 이상(예: 122,130조) 잔존.
- 회계기준 변경 시계열 단절: 매도가능→FVOCI 등으로 account_id 바뀌어 prior 연결 끊김.
- 업종(금융·보험·건설): 비금융 가정 오분류.

## E. Phase2 핸드오프 적합성

- 자기설명성: 한 회사 입력이 "계정 long table + 메타차원(연결별도·기간·통화·세그먼트·주석)"으로 자족적인가.
- 주석↔본문 연결: note 흡수 행이 본문 canonical과 매칭·카테고리 조회 가능한가.
- **provenance(EvidenceRef)**: 각 fact가 원 raw 위치를 추적해 Phase2 grounding이 되나.
- **컨텍스트 크기 = 진짜 쏠림**: 회사별 Phase2 입력 토큰 크기 분포. LLM 컨텍스트 초과 시 에이전트가 통째로 못 읽음.
- 노이즈 비율: 기타주석·미분류가 입력의 몇 %를 차지해 신호를 묻나.

## F. 신뢰·운영

- 결정론 재현성: 같은 raw 두 번 normalize → byte 동일(비결정 dedup 정렬 없나).
- 가짜 exact: mapping_status="exact"가 진짜 표준ID 일치인가(label만 같은 가짜 없나).
- 무음 예외(hollow): try/except 빈 프레임 반환을 "정상 0건"으로 둔갑한 회사연도.
- account_id 복수행 dedup 중재: 한 표 같은 account_id 여러 값 중 대표 선택이 합리적인가.
- **정정공시 버전(최우선)**: 본문이 원본(분식)인가 정정본(세탁)인가 — 분식 5사로 확인. 세탁본이면 탐지 무의미.

## 1급 대상 — 분식 5사 집중

정정공시 버전·분식계정 보존·금액가중 미분류를 분식 5사에서 우선 검증한다. 여기서 분식이 살아있고
왜곡 없이 Phase2로 전달되는지가 도구의 사활이다.
