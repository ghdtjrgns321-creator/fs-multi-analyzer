## (b) Phase1 산출 → 관점 라우팅 (전 회사 동일)

| Phase1 산출(결정론) | 흐르는 관점 | 비고 |
|---------------------|-------------|------|
| review_queue(후보 신호)·ratio 시계열·계정 시계열 | numeric | 수준·추세 이상 |
| flow 큐(현금흐름·차입·운전자본)·ratio(활동성/이익질) | flow | BS-IS-CF 정합 |

| 주석 섹션(28 카테고리) | note | 차입조건·특수관계자·재고평가 등 |
| 미매핑 "기타 중요 계정" | flow/numeric | 분류 못해도 게시 |
| **S7 원문 검토관심 청크** | note | 우발·소송·대주주거래·연결범위 |
| **S9 정정 이력(원본/정정본)** | change | 데이터 출처·재작성 |
| **S10 event 타임라인(시점+조건)** | flow/change/numeric | 자본조달·구조조정·위기 |

라우팅은 **산출 종류**에 거는 것이라 모든 회사 동일(§3). "이 회사에서 의미있나"는 관점 LLM이 판단.

## (c) 관점 LLM 적극 배분 (무엇을 검색·분석하나 — 전 회사 공통)

- 수준/추세 이상(회전율·DIO·이자보상) → 업종 맥락으로 정상/비정상 → numeric/flow
- 무형·개발비 자본화 → 동종 자본화율 비교 → note/industry
- 소급재작성 → 정정공시(S9)·회계정책 주석 → 정상소급 vs 이상 → change
- 우발·소송·대주주거래·연결범위 → S7 원문 + event(S10) → note/flow/change
- 자본거래 timeline(발행·자기주식·양수도) → event(S10) 시점·조건 → flow/change
- KAM·감사의견 → 원문 PART V → external/note

## (d) 정직한 갭 (수집 커버리지)

게이트는 "재료가 나오나"는 통과지만, 일부 재료는 **수집이 선행돼야** 채워진다:
- **주석(note_sections) = 0** (표본 10사): 이 회사들은 FS만 정규화돼 주석 미수집. 주석 관점이
  비려면 `include_notes` 수집 필요. → E2E/운영 시 주석 수집 동반해야 note 관점이 산다.
- **event/correction = 미수집**: S9/S10은 모듈·배선 완료(`include_corrections/include_events`)이나
  기존 corpus엔 아직 미적용. 신규 수집부터 채워진다(전체 corpus 재수집 시).
- **전체 corpus persist**: ~30% 저장본이 _align제거·alias·신규 정규화 미반영(stale). Phase1 운영 전 1회 `--force` 필요.

## (e) 회귀 가드 — 분식 백테스트 (정의 아님, 가드)

분식 6사로 "도구가 망가졌나"만 본다(목표가 아님): 결정론 발굴 recall **5/6**·정상 거짓양성 0.
세토피아(미납입 BW)·디아이동일(연결) 같은 *숫자 급변 없는* 분식은 결정론이 약하고, S7 원문·
S9 정정·S10 event를 LLM이 검색해 받는다(인계 빈칸 0). → 이 가드는 "신규 작업이 기존 발굴을
깨지 않았나" 확인용이며, 게이트 통과 여부는 위 (a) 일반 회사 재료 완전성으로 판정한다.

## (f) human-in-the-loop (PLAN §15)

LLM은 **분식 의심 근거 + 정상 설명 + 반대근거 + 확인질문 + 다음절차**를 제시하되 확정하지 않는다.
사용자(감사인)가 근거를 보고 동의·확인해야 다음으로 간다.

## 게이트 판정

- **통과 기준 = 일반 회사 재료 완전성**: 정상 10/10이 review_queue·ratio·unmapped·flow/change 재료
  산출 → Phase2 투입 가능. ✅
- **남은 조건(운영 전)**: 주석·event·correction 수집 동반 + 전체 corpus persist 1회. (재료 *경로*는
  완성, *채움*은 수집 커버리지 문제.)
- **회귀 가드**: 분식 recall 5/6·FP 0 유지.
- 다음: 10사 E2E(정상·다양 회사로 수집→정규화→신호→Phase2 투입까지 실제 구동).
