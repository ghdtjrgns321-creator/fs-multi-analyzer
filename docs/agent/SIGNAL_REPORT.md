## 5. 2025 threshold 판정

현재 threshold(`divergence_pp_abs: 15`, `yoy_pct_abs: 50`) 기준으로 2025 CFS의 관계 사슬
red flag는 없다. 다만 L4 관점 평가에는 2024→2025 스냅샷을 별도 material로 제공해
약한 신호도 해석 가능하게 했다.

재무제표 기본 합계 계정에 투자원가가 없어 보류했다.
