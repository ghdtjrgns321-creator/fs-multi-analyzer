# SIGNAL_REPORT — L2 MVP1 결정론 계산 결과

> 범위: 삼성전자(`00126380`) 2022~2024 사업보고서, L1 `normalized_financials`.
> 목적: threshold 판정 없이 관계 사슬 계산값만 산출한다.

## 1. 구현 범위

- 입력: 회사/연도별 `analysis.duckdb`의 `normalized_financials`
- 계산 위치:
  - tool DSL: [../../src/analysis_tools](../../src/analysis_tools)
  - 관계 사슬 조립: [../../src/signals](../../src/signals)
- config: [../../config/playbooks/relationship_chains.yaml](../../config/playbooks/relationship_chains.yaml)
- 기준: CFS 우선, OFS 참고

이번 단계에서는 LLM, 에이전트, 주석 인덱서, threshold 판정을 호출하지 않았다.

## 2. 계산 정의

- YoY 증감률: `(당기 금액 - 전기 금액) / abs(전기 금액) * 100`
- 괴리: `account_a YoY - account_b YoY`, 단위는 `%p`
- 0 또는 결측 분모는 `None`으로 방어한다.
- 금액은 L1 금액을 원 단위로 round한 뒤 계산한다.
