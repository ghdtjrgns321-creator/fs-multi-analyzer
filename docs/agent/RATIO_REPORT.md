> 결정론 계산 결과이며 부정·분식 확정 근거가 아니다.

## 1. 계산 범위

- 입력: `data/companies/00126380/{2022,2023,2024}/analysis.duckdb`
- 계정 매핑: [../../config/canonical_accounts.yaml](../../config/canonical_accounts.yaml)
- 지표 정의: [../../config/playbooks/financial_ratios.yaml](../../config/playbooks/financial_ratios.yaml)
- 평균 분모: 전년 값이 있으면 `(전기+당기)/2`, 2022처럼 전년이 없으면 당기말 값 근사.
- 매출채권회전율과 DSO: 순외상매출 계정이 없어 총매출을 대용했다.
- ROI: 투자원가 계정이 없어 계산하지 않았다.

## 3. 계산 상태

2022년 평균 분모가 필요한 ROE, ROA, 매출채권회전율, DSO, 재고회전율, DIO,
총자산회전율, 발생액 비율은 전기 값이 없어 당기말 값을 분모로 사용했다. 2023년과 2024년은
전기·당기 평균을 사용했다. 나머지 지표는 당기 수치끼리 계산했다.

ROI는 투자 단위별 투자원가가 공시 재무제표의 기본 합계 계정으로 잡히지 않아 보류했다.
