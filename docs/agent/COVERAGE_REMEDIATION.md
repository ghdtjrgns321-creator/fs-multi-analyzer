### S11. PHASE1 마무리 — 결정론 최종 커버리지 검사 + Stage2(LLM) 인계 경계 ★종료 게이트
- 무엇: S1~S10 누적 적용 후, 결정론(L0~L2)이 **최종적으로 무엇을 잡고 무엇을 LLM에 넘기는지**를
  전수로 검사·고정한다. PHASE1(결정론) 종료 게이트이자 Stage2(6관점 LLM) 진입 전제.
- 산출물:
  - **(a) 결정론 최종 커버리지표**: 분식 16사 각 분식계정이 결정론 신호로 잡히는지 전수 재측정
    (S1~S10 누적 효과) + 정상 10사 거짓양성. "결정론이 후보로 띄우는 것"의 최종 목록.
  - **(b) LLM 적극 배분 영역** — 기준은 "결정론이 못 잡는 잔여물"(소거)이 **아니라**, **검색·맥락분석으로
    LLM이 판단하는 게 결정론보다 나은 것**(적극 배분)이다. 각 항목은 *LLM이 무엇을 검색·분석해 판단하는가*로 정의:
    · **소급재작성** → 정정공시·회계정책 주석·사업보고서를 **검색**해 회계정책변경/중단영업(IFRS5)/EPS
      소급재계산/오류수정/사업결합 잠정조정 **vs 분식성**(이익·자산 과대 후 하향)으로 **분류·판단** → change
    · **무형자산·개발비 자본화** → 원문 주석 + 동종업계 자본화율을 검색·분석해 과대자본화 판단 → note/industry
    · **절대 수준 이상(DIO·진행률)** → 업종 맥락·동종 비교로 "높게 유지된" 이상의 정상/비정상 판단 → numeric/flow
    · **연결범위 변경** → 주요사항보고서·지분 변동 검색으로 부당 편입 판단 → flow/change
    · **KAM·감사의견·정정공시** → 감사인 지적·정정 사유 해석 → external/note
  - **(c) 에이전트 판단 → 사용자 동의 루프 (human-in-the-loop, PLAN §15 포지셔닝)**:
    LLM은 검색·분석으로 **분식 의심 근거 + 정상 설명 + 반대근거 + 확인질문**을 제시하되 **확정하지 않는다.**
    사용자(감사인)가 근거를 보고 **동의·확인**해야 다음으로 간다. 도구는 "이건 정상 소급으로 보입니다 /
    이건 분식 의심입니다(근거 X)"를 제시하고 **판단·확정은 사람**이 한다. (결정론 = 빠짐없는 후보 발굴,
    LLM = 검색·분석 기반 의견 제시, 사람 = 최종 확인.)
- 완료기준(전수): 16사 결정론 최종 발굴율 + 정상 거짓양성 재측정값을 표로 고정. **16사 각 분식이
  (결정론이 잡음 / LLM에 인계) 중 어디로 가는지 전부 매핑**해 빈칸이 없을 것.
- 상태: [ ] (S1~S10 완료 후 수행)

> **PHASE1 → Stage2 전환**: S11 통과 = 결정론 PHASE1 종료. 이후 Stage2는 결정론 후보(큐) + (b) 인계
