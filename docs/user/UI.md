# UI — 화면 구성 (설계안)

> ⚠️ 현재 구현 전이다. 아래는 **계획된 화면 구성**이며, 구현하면서 실제 화면에 맞춰 갱신한다.
> 기반: [../agent/PLAN.md §5](../agent/PLAN.md)(리포트 구조)·L5 Human, 그리고 기존 프로젝트의
> Streamlit 자산.

## 기술

Streamlit + plotly. 파이썬 단일 코드로 회사·연도 선택 → 분석 → 리포트 열람.

## 화면 구성 (계획)

| 화면 | 내용 |
|------|------|
| 1. 회사·연도 선택 | DART에서 회사 검색, 분석 대상 3개년 지정 |
| 2. 분석 진행 | 5개 에이전트(수치·주석·흐름·변동·반박)의 작업 상태 표시 |
| 3. 리포트 (메인) | Finding 목록을 위험도·유의성 순으로 정렬 |
| 4. Human 검토 | Finding별 승인 / 기각 / 추가 질문 |

## Finding 카드 (메인 화면의 한 항목)

각 Finding은 다음을 한 카드에 담는다 (스키마: PLAN §5):

```
[계정] 매출채권              위험도: High   유의성: 0.8
─────────────────────────────────────────────
숫자 근거 : 매출 +12% / 매출채권 +58% / DSO 41→67일
주석 근거 : 주요 고객 신용위험 집중도 증가
흐름 근거 : 영업현금흐름 감소
반대 근거 : 신규 대형계약 일시 증가 가능성
다음 절차 : 거래처별 매출채권 연령분석표 입수
```

## 차별 요소 (계획)

- **교차검증 과정 펼쳐보기**: 어느 에이전트가 무엇을 주장하고 반박 에이전트가 어떻게
  검증했는지 토론 로그를 열어볼 수 있게 한다(설명 가능성).
- **근거 추적**: 숫자·주석 근거를 클릭하면 원문 위치로 이동(EvidenceRef 기반).
