## 용어 풀이 (비전문가용)

- **XBRL**: 재무제표 숫자에 "이건 매출, 이건 자산총계"처럼 컴퓨터가 읽을 수 있게 붙인 표준
  꼬리표. 사람이 보는 표를 기계가 이해하도록 만든 형식.
- **멀티에이전트**: AI 한 명이 전부 처리하는 대신, 역할을 나눈 여러 AI가 협업하고 서로
  반박하는 구조.
- **결정론 계산**: 증감률·비율 같은 숫자 계산을 AI가 아니라 코드가 한다. 코드는 언제나 같은
  정답을 내지만 AI는 틀릴 수 있기 때문.
- **tool DSL**: AI가 데이터베이스를 자유롭게 뒤지지 않고, 미리 만들어 둔 안전한 분석 함수
  (예: "두 계정의 증가율 비교")만 골라 호출하게 하는 방식.
- **Human-in-the-Loop**: AI가 최종 결론을 내리지 않고, 사람이 검토·승인하는 작업 흐름.

## 왜 이런 선택을 했나 (핵심 원칙)

1. **계산은 코드, 해석은 AI** — 숫자 환각을 원천 차단.
2. **AI는 역할로 나누고, 분석 대상(계정)은 데이터로 흘린다** — 회사마다 다른 계정에 유연 대응.
3. **회계 지식은 코드가 아니라 설정(YAML)에** — 새 산업·계정 추가 시 코드 수정 불필요.
4. **모든 AI 주장은 실제 숫자·주석에 근거** — 근거 없으면 반박 AI가 기각.
