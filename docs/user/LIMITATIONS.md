# 프로젝트 한계 (Known Limitations)

이 도구가 다루지 못하거나 사용 시 주의해야 할 점을 한곳에 정리한다. 입사용/검토용 프로젝트로서
"무엇을 못 하는지"를 숨기지 않고 명시하는 것이 신뢰의 전제다. 세부 근거는 각 항목의 링크 문서를 참조한다.

## 1. 외화재무(비원화) 회사는 분석에서 제외된다

DART에 재무제표를 USD 등 외화로 신고한 회사가 있다(로컬 corpus 기준 약 39개 회사연도, 전 표가 외화).
이 도구는 모든 금액을 원(KRW)으로 가정해 계산하므로, 외화 금액을 그대로 쓰면 환율(약 1,300배) 만큼
규모가 틀어진다. 더 위험한 점은 자산=부채+자본 같은 항등식은 같은 외화 단위라 깨지지 않아, 이 오차가
검산에 잡히지 않고 조용히 통과한다는 것이다.

- **대응**: 온보딩 게이트가 통화 단일성을 검사해, 비원화(외화) 재무 회사는 "원화 분석 부적합"으로
  **차단**한다(분석 진입 불가). 조용히 1,300배 틀린 결과를 내느니 명시적으로 제외한다.
- **미지원**: 환율 환산은 하지 않는다. DART가 환율을 제공하지 않고, 회계상 자산은 기말환율·손익은
  평균환율로 시점이 달라 임의 환산이 오히려 더 부정확하기 때문이다.

## 2. 신규 회사 온보딩은 LLM에 의존한다

신규 회사를 분석에 넣으려면 온보딩 단계에서 LLM 통독 3종(계정 별칭 제안·검토관심 청크 선별(S7)·
정규화 통독(G6))이 실행돼야 한다.

- **비용**: 회사당 약 ₩200~660, 소요 2~5분(대부분 S7 본문 통독). 대형 금융사는 본문이 30만 토큰을
  넘어 비용·시간이 더 든다. 운영 전수(수천 사)는 비용상 수행하지 않는다.
- **실패 시**: API 키 미설정이나 호출 실패 때 분석을 영구 차단하지 않는다. "본문 위험 미선별" 등
  경고를 띄우고 사람이 확인 후 진행한다(silent 누락은 막되, 장애로 멈추지는 않게).
- **별칭 등록은 사람이 한다**: LLM 제안은 후보일 뿐, 회계적 확인 후 사람이 등록한다(자동 등록 금지).

## 3. 서술형 감사관심사항은 S7을 실행해야 전달된다

소송·특수관계자 거래·우발채무 같은 "글로 쓰인 위험"은 정형 주석(XBRL)이 아니라 사업보고서 본문에 있다.
온보딩에서 S7 청크 선별을 실행해야 이 정보가 분석 LLM에 전달된다. 미실행 시에는 빈 채로 두지 않고
"S7 미선별 — 본문 위험 누락 가능" 경고를 분석 입력에 명시한다.

## 4. 게이트(검문)가 보장하는 범위에는 경계가 있다

온보딩 게이트는 정규화 품질을 검문해 불완전한 데이터의 분석 진입을 막는다. 빈/부분 데이터, 재무상태표(BS)
결손, 자본변동표(SCE) 표준화 실패, 외화재무는 차단한다. 다만 다음은 현재 한계다.

- **단일 회사 범위**: 게이트는 한 회사연도만 본다. 여러 회사에 걸친 계정 매핑 충돌(G2)은 보고만 하고
  통과 판정에는 넣지 않는다.
- **수집 실패 표기 미완**: 재무 수집이 네트워크 오류로 실패하면 빈 데이터가 될 수 있다. 게이트의
  데이터 검증(BS 검산 등)이 빈 데이터를 차단하므로 잘못된 분석으로 이어지지는 않지만, "수집 실패"를
  별도로 명시 기록하는 기능은 아직 없다.
- 상세: [P1_AUDIT_HARNESS.md](P1_AUDIT_HARNESS.md)(본질적 한계), [BACKTEST_ANALYSIS.md](BACKTEST_ANALYSIS.md)(도구 약점).

## 5. 이 도구는 부정(분식)을 확정하지 않는다

산출물은 "감사인이 검토할 리스크 후보"이지 분식 확정·자동 적발·성능 보장이 아니다. 모든 발견은
반대 근거·정상 설명·확인 질문·다음 절차를 함께 제시한다. 도구가 무엇을 잡고 무엇을 왜 놓치는지는
[BACKTEST.md](BACKTEST.md)·[BACKTEST_ANALYSIS.md](BACKTEST_ANALYSIS.md)에서 실제 분식 사건으로 검증한다.

## 6. Phase2 멀티에이전트 실호출 E2E 실측 (#1 완료)

6관점 병렬 검토 → 코드 클러스터·점수 → 반박 에이전트 → 의심건 카드 목록까지 결정론 골격과
배선은 코드로 완성·단위테스트 고정돼 있고, **실제 LLM 호출 전과정 E2E를 1개사에 측정**했다
(수집→정규화→온보딩→Phase1→Phase2). 측정 하니스: `data/backtest/_e2e_measure.py`(회사·연도 인자화).

**실측 #1 — 대주산업(00112457/2024, 소형 비금융, 자산 1,114억)**: 가정 단가 입력 $2.5·출력 $10 /
100만 토큰, 환율 ₩1,380(gpt-5.4 실단가 미확정 — 토큰 수에 실단가 대입 시 즉시 재산출).

| 단계                   |      시간 |       비용 |    LLM |
| ---------------------- | --------: | ---------: | -----: |
| 수집(DART 4개년)       |      18초 |         ₩0 |      - |
| 정규화                 |       9초 |         ₩0 |      - |
| 온보딩 게이트          |       5초 |         ₩0 |      - |
| 온보딩 S7(본문 통독)   |      10초 |       ₩329 |      1 |
| 온보딩 별칭 제안       |       4초 |        ₩13 |      1 |
| 온보딩 G6(정규화 통독) |      13초 |        ₩47 |      1 |
| Phase1 리포트          |       5초 |         ₩0 |      - |
| **Phase2(6관점+반박)** |  **93초** |   **₩976** |  **7** |
| **합계**               | **158초** | **₩1,365** | **10** |

- **시간·비용 병목은 Phase2**(시간 59%·비용 72%). 수집·정규화·Phase1은 LLM 미사용으로 무료·고속.
- 입력 313,178 · 출력 20,608 토큰 / 회사. 금융사·대기업은 본문·계정이 커서 S7·Phase2 토큰이 크게 는다.
- 산출: 게이트 통과·검토관심 청크 10·review_queue 18·의심건 카드(계정 13+회사 6)·반박 19.
- 비결정성: LLM이라 재실행마다 의심건 수가 달라진다(관측: 카드 9↔13). 결정론 골격(점수·클러스터)은 불변.
- 측정 중 발견·수정: 토큰 캡처 초기값이 동기경로를 2배로 세던 버그(₩1,699 과대)를 잡아 ₩1,365로 정정.
