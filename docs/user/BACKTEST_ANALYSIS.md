# 백테스트 해부 — 무엇을 잡고, 무엇을 왜 놓쳤나

> Stage1 결정론(LLM 없이 숫자 신호만) 백테스트 결과를 사건별로 해부한다. 목적은 단순 탐지율이
> 아니라 **놓친 사건이 "잡을 수 있었는데 도구 약점으로 놓친 것"인지, "결정론으로는 본질적으로
> 못 잡는 것"인지** 가르는 것이다. 이 구분이 무엇을 고치고(도구 개선) 무엇을 LLM 층에 맡길지를
> 정한다. 정답지·검증방법은 [BACKTEST.md](BACKTEST.md).

## 분류 틀

```
A. 잡힘            — 분식계정이 신호 강도 상위(상위 10)에 떠올랐다.
B. 잡을 수 있었는데 못 잡음 (도구 약점, 수정 가능)
                   — 흔적은 재무제표에 뚜렷한데 도구 설계 한계로 신호화/우선순위에 실패.
C. 잡을 수 없음 (결정론 본질적 한계)
                   — 흔적이 점진적이거나 구조적이라 숫자 시계열만으로는 분별 불가. 주석·동종업계·LLM 필요.
```

## 사건별 해부

### 두산에너빌리티 — A. 잡힘
- 분식: 인도 화력발전 손실 미반영(진행률 과대), 2017~2019.
- 신호: `미청구공사`(dart_ShortTermDueFromCustomersForContractWork)가 2019년 z-score **−16.6**로
  발화, 강도 순위 9위. 진행률 분식의 재무제표 발자국인 미청구공사를 정확히 짚었다.
- 판정: **잡힘.** 다만 공사매출·공사손실충당부채는 합계 계정에 단독으로 잡히지 않아(변동미미)
  미청구공사 한 줄기로 포착됐다.

### 모델솔루션 — A. 잡힘
- 분식: 결산수정(매입 누락분 이연)·유상사급 총액인식, 2022~2023.
- 신호: `당기순이익` 강도 **24.2**, 순위 2위. 결산수정이 손익에 직접 남아 강하게 포착.
- 판정: **잡힘.**

### 아스트 — B. 잡을 수 있었는데 못 잡음
- 분식: 판매된 재고를 매출원가 미처리·재고로 유지(재고 과대), 2017~2022.
- 데이터: 재고자산 460 → 715(+55%) → 1100(+54%) → 1526(+39%) → **723(−53%, 2020 붕괴)**억.
  매출원가는 같은 기간 +12 / +18 / +14%에 그침.
- 신호: 재고자산 신호는 **발화했으나 순위 68위**(강도 1.1)로 묻힘.
- 판정: **잡을 수 있었다.** 두 가지 약점이 겹쳤다.
  1. 단일 계정 z-score 한 줄로는 +55% 재고 급증이 150여 개 신호 속 68위로 가라앉는다(노이즈 매몰).
  2. 진짜 신호는 *관계*다 — **재고는 3년간 3배인데 매출원가는 거의 안 늘었다**(팔리지 않고 쌓임).
     이 재고↔매출원가 괴리는 관계 사슬에 등록돼 있지 않아 포착 못 함. → 관계 사슬 추가로 수정 가능.

### 디아이동일 — B. 잡을 수 있었는데 못 잡음
- 분식: 공동지배기업(동일라코스테)을 연결에 부당 편입(연결 자기자본·수익 과대), 2015~2019.
- 데이터: 수익 146 → 205 → **8,581(+4,088%)**억(2017 편입). 자본총계 5,126 → **20,682(+303%)**억(2019).
- 신호: +4,088%·+303%라는 **거대한 점프가 신호 상위에 없다.** 수익은 약한 신호로 34위에만 매칭.
- 판정: **잡을 수 있었다(흔적은 40배 점프로 명백).** 도구 약점이 원인이다.
  - 신호는 `account_id + label`을 키로 시계열(YoY·z-score)을 만든다. 연결 편입으로 그 해 계정의
    account_id가 바뀌면 **전년과 다른 키로 분리**돼, 40배 점프가 "전년 없음"으로 처리되어
    신호화되지 않는다. → account_id 변경을 흡수하는 매칭(라벨 기준 병합)으로 수정 가능.

### 셀트리온 — B(재고) + C(개발비) 혼재
- 분식: 개발비 과대자본화(2017~2020) + 재고자산평가손실 미인식(2016).
- 데이터:
  - 무형자산(개발비 포함) 6,978 → 7,202 → 7,884 → 8,850 → 10,082 → 14,042억. **+3 / +9 / +12 / +14 / +39%.**
  - 재고자산 2,338 → 1,709 → 1,995 → 1,629 → **3,067(+88%)** → 3,843억.
- 신호: 개발비/무형자산 24위(강도 3.1), 재고는 변동미미.
- 판정:
  - **재고 +88%는 B(잡을 수 있었으나 묻힘).**
  - **개발비는 C(결정론 본질적 한계).** 매년 +3~14%씩 *점진적으로* 자본화하는 분식은 시계열이
    완만해 z-score가 약하다. 적정 자본화인지 과대인지는 **동종업계 R&D 자본화율 비교·주석의
    자본화 요건 검토**가 있어야 갈린다. 단일 계정 숫자로는 분별 불가.

### 세토피아 — B. 잡을 수 있었는데 못 잡음
- 분식: 미납입 BW 인수대금을 납입 처리(금융자산·부채 동시 과대), 2019.
- 데이터: 백테스트는 "데이터부족"(2019 한 해)으로 판정했으나, 확인 결과 **2017·2018이 별도(OFS)
  재무제표로 DART에 존재**한다(216·156행). 연결(CFS)만 보던 처리가 OFS-only 연도를 떨어뜨렸다.
- 판정: **데이터는 있었다.** CFS가 없으면 OFS로 대체하도록 고치면 시계열 평가가 가능해진다.
  (단, BW 미납입의 금융자산↔부채 동시 과대는 1년 내 cross-check라 관계·주석 층이 더 적합.)

### 한국항공우주산업(KAI) — 음성 통제
- 검찰 분식 기소 → 1·2·3심 무죄, 과징금 취소.
- 신호: 무형자산 +46% vs 매출 −30%(2017). 이 괴리로 무형자산이 8위로 떴다.
- 판정: 도구가 **검토 후보로는 적절히 띄웠고**, 검토(법원) 결과는 정상이었다. 이 도구의 포지셔닝
  (부정 확정이 아니라 검토 후보 제시)과 일치한다. 다만 다툼 있던 사건이라 완전한 음성 통제는 아니다.

## 종합

### 결정론으로 "잡을 수 있는데" 놓친 것 = 도구 약점 3가지 (수정 대상)
1. **노이즈 매몰** — 단일 계정 신호가 너무 많이 떠(정상 삼성도 채점대상 79개) 분식계정이 중위권
   (아스트 68위·셀트리온 재고)에 가라앉는다. 강도 정규화·순위만으로는 분별이 약하다.
2. **account_id 변경에 시계열 단절** — 연결 편입 등으로 계정 코드가 바뀌면 거대한 점프(디아이동일
   수익 +4,088%)가 "전년 없음"으로 빠진다. 라벨 기준 병합 필요.
3. **CFS-only 처리의 데이터 누락** — 별도(OFS)만 있는 연도(세토피아 2017·2018)를 떨어뜨려
   "데이터부족"으로 오판. OFS fallback 필요.

### 결정론으로 "본질적으로 못 잡는" 것 = LLM·주석·동종업계 층의 몫
- **점진적 분식**(셀트리온 개발비 매년 +3~14% 자본화) — 시계열이 완만해 안 튄다. 동종업계
  자본화율·주석 비교가 있어야 분별.
- **관계로만 드러나는 분식**(아스트 재고↑ vs 매출원가 flat) — 한 계정의 급변이 아니라 *계정 간
  아귀*가 안 맞는 것. 흐름 관점이 봐야 한다.
- **"움직임은 잡아도 분식인지 정상인지" 판단**(디아이동일 연결 편입이 부당한가, KAI 무형자산이
  과대인가) — 숫자는 후보를 띄울 뿐, 부정 여부는 맥락·주석·반대근거 교차가 판정.

이 결과가 멀티에이전트 LLM 층의 존재 이유를 데이터로 정당화한다. 결정론은 후보를 빠짐없이
줍는 발굴기이고(분식계정 신호 발화 5/6), 정상회사 노이즈와 가르는 판별은 다음 층의 몫이다.

## 수정 후 재실행 (약점 ②③ 반영)

약점 ②(account_id 시계열 단절)·③(OFS 누락)을 **일반 원칙으로만** 수정했다(특정 사건이 통과하도록
맞추지 않음, 채점 잣대 불변). z-score는 과거 관측치 4개 이상일 때만 계산하도록 보수화했다.

```
지표                       수정 전    수정 후
분식계정 신호 발화(다 줍나)   5/6       6/6     ← 세토피아 OFS로 부활, 디아이동일 수익 신호 유지
상위10 엄격 hit(정상과 가르나) 2/6       1/6     ← 두산 미청구공사 9위→12위
```

- **발화 6/6**: 6개 분식회사 모두 분식 난 계정이 신호로 표면화된다(두산 12·세토피아 14·디아이동일 35·
  셀트리온 44·아스트 56위, 모델솔루션 2위).
- **두산이 hit→miss로 내려간 것은 정직한 결과다.** 보수적 z-score로 바꾸자 기존 9위가 적은 표본이
  만든 과대 점수였음이 드러났다. 정답을 알면서도 순위를 끌어올리지 않았다(오버피팅 회피).
- **음성 통제 KAI가 10위로 분식회사들보다 위**라는 점이 핵심을 굳힌다. 강도 순위만으로는 분식
  (두산 12위)과 무죄(KAI 10위)·정상(삼성 채점대상 79신호)을 가르지 못한다.

정리: 결정론은 분식 흔적을 **빠짐없이 표면화하지만(6/6)** 정상 노이즈와 **분별하지 못한다(엄격 1/6)**.
남은 약점 ①(노이즈 매몰)은 튜닝으로 메우지 않는다 — 그건 오버피팅이며, 분별은 본질적으로 LLM·주석·
동종업계 층의 몫이다.

## 노이즈의 정체: 상당 부분이 계산 아티팩트였다 (Tier 1 정리)

앞에서 "노이즈 매몰은 튜닝으로 메우면 오버피팅"이라 했다. 그런데 면밀히 들여다보니 분식계정을
누르던 "노이즈"의 상당 부분이 **진짜 신호가 아니라 계산이 깨진 아티팩트**였다. 이건 튜닝이 아니라
정정 대상이다.

- **하드코딩 버그(P7)**: 관계사슬 엔진이 분석 연도를 데이터가 아니라 설정 리터럴(2022~2025)에서
  가져와, 그 밖 연도 회사는 관계 신호가 전부 죽어 있었다. 데이터 기준으로 고치자 아스트 재고↔
  매출원가 괴리 같은 핵심 신호가 되살아났다.
- **현금흐름표 계정에 YoY%**: 흐름 계정(운전자본변동 등)은 본래 0을 오가 % 가 무한대급으로 튄다
  (−2124%). 레벨 통계 대상에서 제외했다.
- **0 근처 분모/분산**: 전년이 0 근처면 YoY% 가 폭발(−119,580%)하고, 과거 분산이 0 근처면
  z-score 가 폭발(308시그마)한다. 기저 가드(전년 material·같은 부호)와 z 상한 캡으로 막았다.

모두 분식 지식과 무관한 일반 통계·회계 원칙이다. 채점 잣대(상위10)와 신호 임계는 건드리지 않았다.
결과: **엄격 hit 1/6 → 6/6.** 6개 분식회사 모두 분식계정이 상위10에 들었고, 정상 삼성은 clean,
음성 통제 KAI 는 hit 에서 빠졌다(분식계정들이 임계 미달).

## 홀드아웃 검증 — 오버피팅 판정

6/6 은 좋지만 **같은 8개 회사로 계속 고친 결과**다. 가드가 진짜 작동한 것인지, 아는 답이 뜰 때까지
노이즈를 깎은 것인지 in-sample 로는 구별할 수 없다. 그래서 **튜닝에 전혀 쓰지 않은 회사로 검증**했다.
회사를 먼저 고정하고 엔진을 동결한 채 돌렸다.

미사용 분식 3건(증선위 제재로 확정, 실명·출처 재확인):

```
회사                분식                       확정              도구 결과
티피씨메카트로닉스    재고자산 과대(2014~2016)     증선위 과징금 4.35억   재고자산 2위 ★
유네코              차입금을 매출채권 회수로 가장   증선위 검찰고발       매출채권 7위 ★
                    →매출채권 과대·대손 과소(~2019)
본느                재고 과대+비용 이연(2022~2023) 증선위 검찰고발       재고자산 6위 ★
```

정상 5곳(NAVER·KT&G·오리온·한미반도체·영원무역).

결과:
- **분식 3/3 모두 top10 포착.** 처음 보는 분식을 잡았다 → **탐지력은 일반화한다. 오버피팅 아니다.**
- **정상 5곳 중 2곳에서 잔여 극단-% 아티팩트 발견**: NAVER 당기순이익 괴리 −1854pp(강도 123),
  한미반도체 기타수익 +5239%(강도 104). 0 근처 분모에서 % 가 폭주해 강도 100+로 상위를 점령한다.
  튜닝 세트에만 있던 게 아니라 **처음 보는 회사에도 똑같이 나온다 = 일반 결함**이다.

→ 홀드아웃이 두 가지를 동시에 확인해줬다. (1) 탐지 일반화로 오버피팅을 배제, (2) 잔여 극단-%
아티팩트가 일반 결함임을 독립 데이터로 증명. 후자를 고치는 것은 또 다른 튜닝이 아니라 검증된
일반 수정이다. 홀드아웃은 이후 수정의 상시 오버피팅 감시판으로 유지한다.

## 데이터 정리가 드러낸 진실 — 6/6은 깨끗한 데이터에서 안 버틴다

16개사 전수 스캔으로 데이터 위생 버그를 다발로 찾았다(삼성 한 회사로 만들어 다양한 회사에서야
드러난 것들이다).

- **중복행 이중계상**: 같은 계정이 한 해·한 표에 2~4번 중복(두산 135·NAVER 107건) → 합계·구성비·
  YoY 오염. 정규화에서 dedup.
- **소계·항등식 발화**: BS 합계·소계(자산총계·부채총계·유동부채...)가 독립 이상신호로 top10 점령
  (세토피아 8/10). `자산총계≡자본과부채총계`가 같은 값 2슬롯. 이상신호에서 제외(합계는 비율 계산엔
  계속 사용).
- **매출 매핑 불일치**: 제조사는 매출이 잡히나 NAVER·KT&G(영업수익형)는 누락 → 매출 기반 사슬이
  조용히 죽음. alias 보강.

이 데이터를 씻자 **상위10 strict 6/6 → 2/6** 으로 내려갔다. 이는 데이터 정리가 망친 게 아니라,
**기존 6/6이 부분적으로 소계·중복 노이즈에 기댄 결과였음**을 드러낸 것이다. 깨끗한 상태의 진실:
소형사에는 큰 폭으로 출렁이는 계정(미수금·보증금·외환차익·파생상품)이 수두룩하고, 분식계정의
신호(재고 +55%)는 그중 제일 큰 게 아니다. 분식은 *관계*(재고↑ vs 매출원가 flat)로 드러나지 단일
계정 % 크기로 드러나지 않는데, 순위는 % 크기로 매긴다. 그래서 분식계정이 13~16위에 머문다.

6/6을 억지로 되찾으려 더 깎는 것은 오버피팅이다. 그렇게 하지 않았다.

## 지표 재정의 — 결정론은 발굴기, 판별은 다음 층

결정론 층의 역할은 **후보 발굴**이지 최종 순위가 아니다. 그래서 성공 기준을 둘로 나눠 정직하게
병기한다.

```
지표                          튜닝(6사)   홀드아웃(3사)   의미
발굴 recall(분식계정이 빨간불을 냈나)   5/6        3/3        결정론의 본래 역할 = 후보로 띄움
상위10 strict(정상 노이즈 위로 올렸나)  2/6        3/3        판별 — 관계·LLM 층의 몫
```

- **발굴 8/9**: 9개 분식계정 중 8개가 결정론 신호로 표면화됐다. 못한 1건(세토피아)은 금융부채
  라벨이 데이터에 없고 금융자산이 단일연도뿐이라 YoY 불가 — BW 분식은 본래 표면화가 어려운
  케이스로, 정직하게 miss로 남긴다.
- **strict 5/9**: 순위로 정상 변동과 가르는 일은 결정론 단독으로는 한계가 분명하다. 이것이
  멀티에이전트 LLM·관계신호 층이 필요한 이유를 다시 확인해준다.
