# 변환 경계 권위 승격 설계 — 4결함 구조 해결

> 2026-07-11 확정. LG생활건강 27장 전수 감사에서 확인된 4계열 결함
> (시계열 부호 아티팩트 · LLM 억원 환산 오류 · 정준계정 라벨 오매핑 · 외부검색 품질)의 구조적 해결.
> 관련: [docs/user/TROUBLESHOOT.md](../../user/TROUBLESHOOT.md), memory `lghh-e2e-card-audit-defects`.

## 원칙

4개 결함의 공통 구조: **각 변환 지점마다 시스템이 이미 보유한 더 권위 있는 진실이 있는데 쓰지 않는다.**
해법은 사후 검사 규칙 발명(정규식 스크러빙)이 아니라, 보유 데이터를 각 변환 경계의 권위로 승격하는 것.

| 결함               | 보유한 진실                      | 승격 방식                      |
| ------------------ | -------------------------------- | ------------------------------ |
| 부호 반전 아티팩트 | 다음 해 보고서의 재표시된 전기값 | 데이터층 정규화                |
| 억원 환산 오류     | 원 단위 원값                     | 생성 원천 차단(코드 환산 투입) |
| 라벨 오매핑        | 공시 원문 계정명                 | 표시 권위 교체                 |
| 외부 수치 오염     | 내부 공시값                      | 경계 대사(structured output)   |

## 설계 1 — 시계열 표기변경 정규화

시계열 빌더(연도별 당기값 스티칭 지점)에 cross-report 대조 단계 추가.
계정의 t년 당기값 v_t와 t+1년 보고서의 전기 재표시값 r_t를 round 후 비교:

- `|v_t| == |r_t|` 이고 부호 상이 → **표기변경**. 최신 보고서 표기를 권위로 v_t 부호를 정규화,
  시계열 메타에 `presentation_change` 기록. LLM 입력에 정규화 사실 1줄 노출.
- `|v_t| != |r_t|` → **재표시(restatement) 후보**로 플래그(억제가 아니라 신호 승격).
- 일치 → 무변경.

계정·부호 하드코딩 없이 전 계정 동일 적용.

## 설계 2 — 금액 환산을 코드로

- 프롬프트의 "억/조로 축약해 써라" 지시 삭제 → "입력에 제공된 환산 표기를 그대로 사용, 자체 환산 금지"로 교체.
- `format_krw()` 유틸 1개: 원 단위 정수 → `"1조 2,534.7억"` 형태. 카드 재료 생성 단계에서
  LLM 입력의 모든 금액에 병기. LLM이 나누기할 일 자체를 제거하므로 산문 숫자 사후검증 불필요.

## 설계 3 — 라벨 권위를 공시 원문으로

- 정준(canonical) 계정명은 내부 조인 키로 강등. LLM 입력·카드 표시 라벨은 공시 원문 계정명(account_nm).
- 일회성 전수 감사: 정준명 vs 매핑된 계정들의 공시 라벨 불일치 리포트(코드 생성, 분모 명시)로
  `FinanceCosts→이자비용`류 오매핑 일괄 발견·수정. 이후 라벨 원천이 공시 원문이라 재발 구조 차단.

## 설계 4 — 외부 경계 대사 3건

- **(a)** 외부 에이전트 structured output에 `claimed_figures`(수치 주장 목록) 필드 추가,
  코드가 내부 공시값과 대조해 ExternalRef에 일치/불일치/대조불가 마킹. 요약문 정규식 파싱 금지.
  불일치 수치는 UI에서 "외부 주장(공시와 상이)" 구분 표시.
- **(b)** `select_external_targets`: 우선순위 상위 K장(기본 3)은 resolved 여부 무관 포함.
  resolved 제외 규칙은 나머지에만 적용.
- **(c)** 저장 전 리다이렉트 URL 1회 해소(follow)해 최종 기사 URL 저장, 실패 시 현행 URL + 출처 도메인 병기.

## 비범위

- 이미 저장된 과거 카드의 사후 스크러빙(재생성으로 해결).
- 산문 텍스트에서 숫자를 추출·대조하는 통합 검증 게이트(B안 기각).
- 서사 템플릿화(C안 기각).
