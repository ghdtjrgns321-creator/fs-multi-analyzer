# README 아웃라인 계약 — Disclosure Review Agent (multi-BS)

- **대상 독자**: 채용·평가자(회계법인/기업). 단 기술 설명도 포함.
- **상태**: 2026-07-15 사용자 확정 발화 3건 채록(아래 원문).
- **스타일(확정)**: 톤=담백(과장·은유 금지) · 구조 밀도=세분 · 제목형=기능형
- **깊이(전역 방침)**: 채용 평가자 기준 — "너무 깊은 부분 아닌 경우 추가해서 풍부하게"
- **내용 방침**: **over-inclusive(눌러담기)**. 사용자가 초안에서 선별·수정 예정.

## 사용자 육성 채록 (원문 보존)

1. "채용 평가자 상대이지만 기술적인 설명도 너무 깊은부분 아닌경우 추가해서 풍부하게 만들어줘"
2. "기술스택을 9로, 한계를 8로"
3. "아직 내용내가 선별할만큼 내머릿속에서 정리되지 않았으니까 최대한 리드미에 꽊꽊눌러담아서 over 내용으로 써줘 거기서 내가 선별해서 다시고칠거니까"

> 3번이 섹션별 내용 선별 인터뷰를 대체하는 명시 지시(스킬 ② "생략은 사용자 명시 때만" 충족).
> 따라서 섹션 내용은 정리본(FINAL-REPORT) 재료를 최대 포함으로 채우고, 선별은 사용자 후속 턴에 위임.
