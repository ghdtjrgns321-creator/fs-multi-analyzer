### plan.md "264" 와의 정합 (왜 439인가)

plan.md의 264는 **양측 모두 범주 분류된** 쌍의 행수다. 본 측정 439 = 264(양측분류 41쌍)
+ 175(한쪽이 `cf?`/`pl?` 미분류 42쌍). 미분류측 쌍은 plan 시드가 "같은 범주(미분류 동일)"로
흡수해 264에서 빠졌다. 본 triage는 **439 전수**를 분류하되, `cf?`/`pl?` 미분류측 쌍은
범주 도출 노이즈로 보고 **보수적으로 동의어(id 유지)** 처리한다(§5 과분류 금지 준수).

### 분류 판정 기준(범용)

- **진짜충돌**: 두 canonical이 가리키는 경제적 실질이 다르다. id측이 이 행에 틀렸고
  label측이 사람 의도. 예) IS 수익↔이익소계, CF 잔액조정↔현금흐름소계, BS 평가손익↔법인세효과.
- **동의어**: 같은 경제 실질인데 이름·표현·취득/증가 어휘 차이로 범주가 갈림. id 유지해도 의미 보존.
  - 거짓양성 유발 경계 패턴(아래 §거짓양성 패턴) 해당 시 무조건 동의어.

### E. CF 취득↔증가/처분↔조정 계열 (투자↔조정, 동의어) — 89행

가장 큰 동의어 군집. 금융자산 **취득**(id cf_investing) ↔ 금융자산 **증가**(label cf_adjust)는

## 거짓양성 유발 범주 경계 패턴 (Phase 2 범주 도출 보수화 항목)

1. **BS '지분/자본' in 자산명** → bs_equity 오분류 (지분법적용투자=자산). 규칙: '투자' 포함 시 자산 우선.
2. **BS '채무/채권'** → 자산·부채 양측 등장, 이름만으론 미결. 보수적 동의어.
3. **BS '손익/평가' in 자본누계** → 기타포괄손익누계액=자본인데 bs_asset 오분류.
4. **CF '증가/감소/증감'** → cf_adjust 분류되나 투자자산 맥락선 취득/처분 동의어. 산술검산 전 뒤집기 금지.
5. **CIS '법인세효과'** → OCI 세효과 vs 손익 법인세 경계. 산술(IS_tax) 교차검증 필요.
6. **정부보조금 수취/수령 류**(plan.md 예시): 동일 수령인데 유출입/기타로 범주 갈림 → 동의어.
