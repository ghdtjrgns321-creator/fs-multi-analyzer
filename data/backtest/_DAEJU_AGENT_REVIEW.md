## 4. 핵심 통찰 — 삼성 진단이 대주에서 실증됨

- **numeric·flow·change 3관점이 같은 데이터(CFS 본문 패널)를 봐서 주장이 크게 겹친다.**
  운전자본변동·유형자산취득·법인세비용이 3관점에 중복 등장. flow="관계"·change="시계열"이라지만
  실제론 같은 계정을 다른 말로 표현. → `HANDOFF_ROOT_REDESIGN.md`의 "내부 3관점 데이터 단일성" 실증.

### 4b. 왜 비효율/빈손인가 — 관점별 원인이 다름 (실측 근거)
- **flow(비효율)**: 관계 재료를 **받긴 받음**(growth_divergences 8·direction_checks 3·cfs_ofs_gap 1건).
  그러나 numeric과 동일한 account_metrics_panel(급변 패널)을 **함께** 받아, 급변 숫자(운전자본 -278%·
  유형자산취득 +177%)가 미묘한 관계 괴리(매출↔재고 3.89pp)를 압도 → LLM이 급변에 끌려 numeric 복제.
  자기 고유 신호(현금순증감 연결-별도 30% 괴리)를 놓침. **원인=입력 설계(관계+급변 혼합), 고칠 수 있음.**
- **change(비효율)**: 고유 영역인 소급재작성 신호 **0건**(restatement_signals·history 모두 0, 대주 재작성 없음).
  남은 재료가 panel yoy(numeric과 100% 동일)뿐 → numeric 복제. volatility_cv만 유일 차이.
  **원인=고유 재료 회사 의존(재작성 있으면 작동).**
- **external(빈손)**: 재료 status="external query generation only" — 검색 쿼리 생성 재료만 받고 실제
  외부 근거(뉴스·URL) 수집 파이프 미구현(events.json 48B). source_url 필수인데 근거 0이라 전량 탈락.
  **원인=데이터 소스 부재(파이프 구현 필요).**
- **고유 가치는 다른 데이터를 보는 관점에서 나온다**: note(주석)·industry(peer)만 numeric이 못 보는
  차원(담보·특수관계자·KAM / 업종 대비)을 제공. external은 데이터가 없어 빈손.
- **note는 대주에선 살았다(8건)** — company scope로 냈기 때문. 삼성에선 account scope로 내
  본문 인덱스에 없어 탈락. **관점의 scope 선택(우연·프롬프트)에 grounding 생존이 갈리는 불안정** 잔존.
- **치명적 누락은 없음**: 6관점이 "잡아야 할 걸 놓친" 건 없다. D(현금)는 당기 YoY +17%로 평범하고
  방향이 개선이라 놓쳐도 되는 급(내 초기 D 과대평가 정정), H(관계기업투자)는 금액 3.9%·완만·지분법
  설명으로 놓칠 수 있는 급. 삼성의 3대 사각(별도 +9,644%·주석 196조 통째 누락)과 격이 다르다.
