## 1. 측정 중 발견한 1차 측정 아티팩트 (자백)

곧이곧대로 보고하지 않고 해부한 결과, 초기 측정에서 **가짜 불일치 2종**이 나왔고 수정했다.

- **CF 당기순이익 오매칭**: `label LIKE '%당기순이익%'`가 CF의 *"당기순이익조정을 위한 가감"*
  (현금흐름 조정 항목)을 잡아 IS와 불일치로 보였다. 두산 2015 CF가 +2,796,808백만(조정가감)
  으로 잡혔으나 실제 CF 당기순이익은 −1,750,899백만으로 **IS와 정확히 일치**. 조정·가감·차감전
  제외 후 35 회사연도 전부 일치.
- **CIS 귀속분 오매칭**: 아스트 2016에서 *"지배기업 소유주 귀속 당기순이익"*(7,257백만)을 먼저
  집어 IS(6,188)와 1,069 차이로 보였다. canonical `당기순이익`(전체귀속)을 우선하니 일치.

→ 교훈: 당기순이익은 IS/CIS/CF/SCE 4표에서 라벨 변형(귀속분·조정항목)이 많아 단순 키워드
매칭이 위험. canonical 우선 + 파생항목 배제가 정답.

## 2. B 항등식 — 잔여 측정

### 2.1 구조 항등식 (견고)
- 자산=부채+자본, 유동+비유동=자산/부채총계: **측정 가능 전 회사연도 diff 0**.
- 당기순이익 4표(IS·CIS·CF·SCE marker) 일치: **전 회사연도 diff 0**. 백만원 단위 완전 일치.

### 2.2 손익항등식 NI = 법인세비용차감전순이익 − 법인세비용
`ok 21 / discontinued_or_other 5 / tax_sign_inconsistent 5`

- **중단영업(두산 2015~2019, 5건)**: 표준식·부호반전식 둘 다 불성립. 두산에너빌리티는 사업부
  매각으로 *계속영업손익 + 중단영업손익 = 당기순이익* 구조라 세전−세금 항등식이 본질적으로
  성립 안 함. **정상 사유**(Phase2는 중단영업 행을 별도로 봐야 함).
- **법인세 부호 비일관(아스트 2019~2022·셀트리온 2020, 5건)**: 표준식은 깨지나 *세전＋법인세=NI*
  (부호반전식)가 성립. raw 원천을 확인하니 **공시 자체가 법인세비용을 음수로 표기**(셀트리온
  2020 raw: 세전 6,572억 + 법인세 −1,314억 = 순이익 5,257억). 정규화 결함이 아니라 원천 특성.

### 2.3 SCE roll-forward (⚠ 결함)
기초자본 marker + Σ변동 marker = 기말 자본총계 marker 단순검산이 다수 회사연도에서 불성립.
원인을 해부한 결과 **두 가지**:
1. **배당변동 부호**: 자본 차감인 배당이 양수 marker로 저장. `2 × 배당 ≈ diff`가 거의 정확히
   성립(삼성2024 배당 10,912,062 → diff −21,824,124 = 2×배당). 자기주식변동도 동일.
2. **미분류 변동의 '기타 중요 계정' 적재**: 두산 2015는 변동 marker 14건이 '기타 중요 계정'으로
   떨어져 합 +8.9조로 폭발(배당 무관 잔차). SCE 변동 분류(change_canonical) 미흡 + marker 중복.

→ SCE의 **잔액(기초·기말)과 당기순이익 marker는 정확**(4표 일치로 입증). 손상된 것은 **변동
내역의 합산 정합성**. Phase2가 SCE로 자본변동을 분석/검산하려면 (a) 차감변동 부호 보정,
(b) 변동 marker 중복제거·분류 보강 필요.

## 3. C 분류 일관성 (견고)
- **회사간 비교가능성**: 한 canonical이 회사마다 다른 statement(sj_div)로 매핑되는 분기 **0건**.
  같은 경제실질이 회사 무관 같은 canonical으로 흐른다. IS/CIS 호환쌍만 다중 sj_div이며 정상.
- **소계 식별**: is_subtotal 15종(유동자산·자산총계·부채총계·자본총계·기초자본 등)이 config로
  식별되고, 소계와 구성 line item이 함께 게시됨(이중게시는 의도된 설계, universal 신호에서
  소계 제외로 처리). 가짜 소계·구성 누락 없음.

## 4. D 부호·스케일
- **매출원가·판매비와관리비·이자비용·기타비용**: 전 회사연도 **양수 일관**.
- **법인세비용**: 양수(비용)/음수(수익 또는 차감표기)가 회사·연도별 혼재. 8개 연도 음수
  (아스트 4·셀트리온 1·삼성 2·KAI 1). 삼성2022 −92,136억은 실제 법인세수익(이연법인세) 공시와
  일치. §2.2의 부호반전 5건은 원천 표기 특성. **실효세율 등 법인세 부호 의존 계산은 Phase2에서
  회사별 검증 필요**.
- **source-scale 이상치**: 비소계 line item이 자산총계 5배 초과하는 단위혼입 **0건**(1차 sanity
  가드 + 통화 정규화로 해소된 상태).

## 5. E provenance·주석연결·Phase2 입력
- **raw 행 추적 불가(❌)**: `normalized_financials`에 rcept_no/ord/source_file 등 원 raw 행
  식별자 컬럼 **0개**. account_id+label+sj_div+fs_div로 raw와 재join은 가능하나, **어느 보고서
  (정정공시 포함)·몇 번째 행에서 왔는지 직접 추적 불가**. Phase2 grounding(근거 행 인용)에 제약.
- **주석↔본문 연결 키 부재(❌)**: note_facts_classified의 concept은 `udf_BS_2017..._CurrentLiabilities`
  (회사 커스텀) 또는 prefix 없는 표준명 형태로, 본문 canonical account_id(`ifrs-full_*`·`dart_*`)와
  **직접 매칭 0건**(전 회사연도). 주석 facts를 본문 계정에 붙이려면 account_id가 아니라 한글
  라벨/category/concept suffix 파싱 기반 매칭이 필요. (concept suffix에 `CurrentLiabilities` 등
  표준 element명이 들어있어 향후 suffix 파싱 여지는 있음.)

## 6. F 신뢰성 (견고)
- **가짜 exact 0건**: `mapping_status=exact_taxonomy_match` 행 중 account_id가 비표준(공백·한글·
  `-표준계정코드 미사용-`)인 경우 **전 회사연도 0건**. exact 라벨은 실제 표준코드를 동반.

자산=부채+자본·순이익 4표 일치가 견고하고, 동일한 SCE 부호·주석연결 갭을 공유한다. 즉

관문이지 분식 판별기가 아님이 재확인됨.

## 8. Phase2 이행 전 권고 결함 목록 (우선순위)

1. **(중) SCE 변동 부호·분류 보정** — 배당·자기주식 등 차감변동 부호 정규화, 미분류 변동의
   '기타 중요 계정' 적재·marker 중복 정리. SCE 자본변동 분석을 쓸 경우 필수.
2. **(중) 주석↔본문 연결 키** — account_id 직접매칭 불가. 한글 라벨/category/concept suffix
   기반 매칭 레이어 필요(Phase2 grounding 품질 직결).
3. **(하) provenance 컬럼** — rcept_no·ord 등 raw 행 식별자를 normalized에 보존하면 정정공시
   추적·근거 인용이 가능해짐(S1에서 prior_amount는 보존, 출처 메타는 미보존).
4. **(하·주의) 법인세 부호** — 부호 의존 계산(실효세율) 시 세전＋법인세=NI 검산으로 부호 판별 후 사용.

중단영업·법인세 부호·무음 empty는 **원천/정당 사유**로 보정 대상이 아니라 Phase2가 인지하고
다뤄야 할 데이터 특성이다.
