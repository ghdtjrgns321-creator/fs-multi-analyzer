## 회사별 소견
### 00409681 (2018–2021)
- 이야기: 2018~2019는 외형 확장과 대규모 자금조달·무형자산/재고 급증이 동반됐고, 2020~2021은 매출 급락·연속 대규모 순손실·자본 훼손이 이어진다. 2019의 공격적 확장 후 2020~2021 급격한 실적 붕괴가 재무 이야기상 매우 크며, 인수/사업권·전환사채·신주인수권부사채 등 복합금융이 많아 Phase2 확인 필요성이 높다.

- 발견:
  - [P2후보] 2019년 대규모 사업확장/인수 흔적 대비 수익성 연결이 약함 — 근거: 2019 CF에 `영업권의 취득(사업권양수대금) 137,129`, `주식발행 88,811`, `장기차입금차입 72,300`, `투자활동현금흐름 -158,590`, 동시에 당기순이익은 `499`에 불과(§A IS, §A CF). 대규모 인수/자금조달이 실질 이익창출로 연결되지 않았고 이후 2020 손실 전환으로 이어짐.
  - [P2후보] 2019→2020 매출 급락과 대규모 적자 전환이 비정상적으로 큼 — 근거: 매출 `144,614 → 54,493`, 당기순이익 `499 → -37,657`, 영업이익 `14,307 → -19,083`(2019/2020 §E, §A IS). 단순 경기변동 수준을 넘어 사업가치 훼손 또는 인수자산 손상/사업 실패 의심 신호.
  - [P2후보] 2019 인수 이후 무형자산이 크고 2020~2021에도 잔존하나 실적은 계속 악화 — 근거: 무형자산 `176,144(2019) → 125,184(2020) → 122,235(2021)`로 매우 큰데, 같은 기간 당기순이익 `499 → -37,657 → -33,722`, 자본총계 `218,067 → 185,561 → 145,448`(§A BS, §E). 인수자산/영업권 평가의 적정성, 손상 인식 시기, 사업권 회수가능성 점검 필요.
  - [P2후보] 재고가 매출 대비 과중하고 2020~2021에 특히 비효율적 — 근거: 재고자산 `110,000(2018) → 152,616(2019) → 168,533(2020) → 171,395(2021)` 반면 매출은 `117,013 → 144,614 → 54,493 → 81,162`(§E). 2020은 재고 `168,533`이 매출 `54,493`의 약 3배 수준으로, 판매부진·평가손실·채널 적체 가능성 시사.
  - [P2후보] 매출채권 변동이 매출 추세와 완전히 동행하지 않아 매출의 질 확인 필요 — 근거: 매출채권 `45,919(2018) → 21,208/시계열상 전기 23,377(2019~2020 비교) → 8,661(2020) → 15,999(2021)`이고 매출은 `117,013 → 144,614 → 54,493 → 81,162`(§A BS, §E). 2019 매출 증가에도 채권 급감, 2020 매출 급락과 함께 채권 급감, 2021 재상승 패턴으로 매출 인식/회수구조 변화가 큼.
  - [P2후보] 영업현금흐름이 이익과 지속적으로 괴리되며 2020~2021 현금창출력 저하 — 근거: 2019 영업활동현금흐름 `21,372`로 흑자이나 당기순이익 `499`, 2020 영업활동현금흐름 `-8,819`에 당기순손실 `-37,657`, 2021 영업활동현금흐름 `-4,867`에 당기순손실 `-33,722`(§A CF, §A IS). 손실기업으로 전환된 뒤 현금창출도 받쳐주지 못함.
  - [원공시] 2020 기타포괄손익 중 자산재평가손익 `6,728`이 대규모 순손실을 일부 상쇄 — 근거: 2020 CIS에서 `기타포괄손익 8,903`, `자산재평가손익 6,728`, 총포괄손익 `-28,754`(§A CIS). 손실 국면에서 평가이익 비중이 커 보이며, 이는 원공시 특성으로 재평가 대상·근거 확인 필요.
  - [P2후보] 자본이 2019 정점 후 급격히 잠식되며 결손금 누적 확대 — 근거: 자본총계 `120,563(2018) → 218,067(2019) → 185,561(2020) → 145,448(2021)`, 이익잉여금 `4,398(2018) → 2,766(2019) → -26,396(2020) → -55,141(2021)`(§A BS, §E). 외부 자금유치로 부풀린 자본이 손실로 빠르게 소진되는 흐름.
  - [원공시] 2021 신주인수권부사채 등 복합금융 의존이 큼 — 근거: 2021 BS에 `유동성신주인수권부사채 30,482`, `유동성전환사채 24,392`, `사채 9,000`, `유동성사채 4,181`; CF 미분류에는 `신주인수권부사채의 발행 30,000`이 큼(§A BS, §C, §A CF). 원공시상 자금조달 구조가 복잡하여 희석·상환압박 리스크 확인 필요.
  - [P1결함] 2020 SCE에서 의미적으로 다른 raw label이 같은 canonical로 병합된 정황 — 근거: §I에 `[OFS/SCE] 연결대상범위변동 ← raw 2개 label: 전환사채 조기상환 / 신주인수권 행사` 명시. `전환사채 조기상환`과 `신주인수권 행사`는 경제적 성격이 다른데 동일 canonical `연결대상범위변동`으로 묶인 것은 의미적 오매핑 가능성이 높음.
  - [P1결함] 2021 CF의 큰 비표준 자금조달 계정이 canonical 체계에 흡수되지 못함 — 근거: §C 미분류 상위에 `CF CFS 신주인수권부사채의 발행 ... 30,000`, `CF OFS 신주인수권부사채의 발행 ... 30,000`이 그대로 남아 있음. 이는 재무적으로 중대한 현금유입인데 표준 canonical에 포섭되지 않아 커스텀계정 보존은 됐더라도 의미 분류가 부족함.
  - [P1결함] 주석 분류가 4개년 내내 사실상 실패 수준으로 저적재되어 고위험 주석 렌즈가 작동하지 않음 — 근거: 적재율 `147/906(16%)`(2018), `164/938(17%)`(2019), `137/953(14%)`(2020), `145/921(16%)`(2021), bucket도 거의 `흡수/기타주석`뿐이고 `분식 고가치축 fact 0건`(§H 전 연도). 특수관계자·차입약정·보증·담보 같은 핵심 주석이 전혀 분류되지 않은 것은 정규화/분류 파이프라인의 실질적 미포착.
  - [원공시] 시계열 전기값 불연속/소급재작성 정황 — 근거: 2020 §E 전기 자산총계가 `550,328`인데 2019 당기 자산총계는 `578,756`; 2020 전기 매출채권 `23,377`도 2019 당기 `21,208`과 다름(2019 §E, 2020 §E). 이는 전기 재작성 또는 기준 변경 가능성으로, 원공시 확인 질문 대상.
  - [원공시] 2021도 전기 자산·자본이 2020 당기와 불일치 — 근거: 2021 §E 전기 자산총계 `520,443`은 2020 당기와 일치하나, 전전기 `550,328`은 2019 당기 `578,756`와 불일치했고 2020에서도 이미 재작성 흔적 존재. 또한 2020 §E 전기 부채총계 `332,261`은 2019 당기 `360,689`와 차이. 연속성 측면에서 원공시상 소급수정 히스토리가 있는 회사로 보임.
  - [원공시] 2021 법인세납부가 음수(`-2,142`)로 표시되어 환급/정산 성격일 가능성 — 근거: 2021 CF `법인세 납부, 영업활동 -2,142`(§A CF). 부호만으로 결함이라 단정할 수 없고 실제 세금환급 또는 정산 결과일 수 있어 원공시 확인 대상.
  - 특이사항 없음(부분) — 근거: BS 기본 항등식은 4개년 모두 맞고(§B), raw 미출현 0건으로 주요 값 소실 증거는 없으며(§D), 본문 병합 collapse도 2020 SCE 1건 외 대체로 안정적(§I). 따라서 핵심 이슈는 산술 오류보다 사업확장-붕괴 서사와 주석/의미 분류 미흡에 있음.
