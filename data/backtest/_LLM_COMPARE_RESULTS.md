# LLM 홀리스틱 비교 결과 — 내 공장(A) vs gpt-5.4(B), 10 고위험사

> 2026-06-14. 입력(회사별 다년 dump)·프롬프트(9렌즈 `_HOLISTIC_AUDIT_PROMPT.md`) 동일, **모델만 다름**.
> A = 이번 세션 공장(general-purpose, 세션 모델) → `_holistic_findings/chunk_N.md`.
> B = gpt-5.4(`dashboard/onboarding.py:run_llm_holistic`, UI 온보딩과 동일 경로) → `_llm_compare/<corp>_gpt.md`.
> 10개사 전부 status=ok 산출(findings 2.6k~4.9k자). 비교는 known 분식 정답지 6 + 강한 P2후보 4.

## 결론 요약

- **gpt-5.4는 UI 온보딩 홀리스틱 모델로 충분하다.** known 분식 신호를 내 공장만큼, 일부 유형(연결범위·재고과대)에서는 **더 직접적으로** 짚었다.
- **단, 한 가지 약점**: gpt-5.4는 dump의 "원/백만 혼재 표시"를 스케일 결함으로 **반복 오판**(거짓 P1결함 최소 4건). 매핑은 전부 정상이었다. → 채택하되 dump 렌더러를 일괄 ÷1e6로 고치거나 프롬프트에 표시 주의를 넣으면 거짓경보가 사라진다.

  - 00118345/2018: 당기순이익 13,825백만 중 **비지배 13,801·지배 24백만** → 부당연결 entity의 이익이 비지배로 빠지는 분식 signature. A는 "재무 이야기 정합, P2 0건"으로 놓침.

- **A가 더 정밀했던 케이스 1건(00159616)**: A는 매출 소급재작성을 raw 원문까지 추적(2017 14.5조→2018 전기 13.8조, 차이 682,228백만)해 분식의 직접 증거를 제시. B는 자산·자본 총계 B5만 보고 "큰 단절 없음"으로 결론 → 정작 분식 계정(매출)의 cross-year 재작성을 못 봄. (단 B도 공사 수익인식·계약자산 리스크는 P2로 지적.)
- **둘 다 못 잡은 2건(01091382·00657783)**: 미납입 BW·총액매출 과대 모두 known 정답지가 "손익영향 제한적·탐지난이도 높음"으로 분류한 미세 분식. 두 모델 다 주변 위기(자본잠식·수익성둔화)는 포착.

**판정: gpt-5.4는 known 분식 신호 포착에서 내 공장과 대등하며, 연결범위·재고과대형에서는 우위.**

- **B의 [P1결함]은 과다 계상**: 회사당 평균 4건 vs A는 0~3건. 과다분의 핵심은 **dump의 원/백만 혼재 표시 artifact를 스케일 결함으로 오독**(검증한 4건 전부 account_id·canonical 정상, 실제 원-단위 미세값). A는 dump 렌더러(`_p1_company_review.py` L156 임계 로직)를 이해해 이 함정을 피했고, B는 렌더된 텍스트만 봐서 빠졌다.
- **단 B의 민감도는 진짜 결함도 잡는다**: A가 잡은 핵심 P1(00148504 발행사채→주식발행 1.4조)을 gpt-5.4가 **독립적으로 동일 포착**. 노이즈만 내는 게 아니라 진성 매핑오류도 찾되, 표시 artifact를 거를 컨텍스트가 없을 뿐.
- **A 단독 포착 1건(00367844 영업창출현금→당기순이익)**: account_id가 exact_taxonomy_match로 숨은 element 의미충돌 — A의 정밀 우위 영역.

## P2 후보(재무위험 서사) — 깊이 대조

- **대등하거나 B가 더 풍부**한 경우가 다수. gpt-5.4는 운전자본·이익현금 괴리·FVTPL 손익변동성·배당정책 비정합을 정량 근거와 함께 촘촘히 나열.
  - 00148504: A·B 모두 "이익 -57% vs 자산·현금 급팽창" 동일 포착, B는 FVTPL/환율 손익 급반전 변동성 추가.
  - 00367844: A·B 모두 "흑자 vs 영업현금 대규모 마이너스(2022 NI+151,899 vs 영업CF-123,119)" 동일, B는 다음해 채권 반감·현금 반전까지 추적.
  - 00102760: A·B 모두 결손누적·유동화채무 의존·계속기업 의심 포착(거의 동일 결론).
- A의 차별점은 **분식 원천추적**(raw CSV·duckdb 4중 재현)과 **표시 artifact 분별**. B의 차별점은 **재무비율·추세 서사의 망라성**.

- **UI 온보딩 채택: gpt-5.4 확정 권장.** 분식 위험 신호 포착이 핵심 목적인 온보딩 전처리에서 gpt-5.4는 내 공장과 대등 이상이고, 연결범위·재고과대형 분식은 더 잘 짚는다.
- **채택 시 보정 1건(거짓 P1 제거)**: 둘 중 하나면 충분.
  1. (권장) dump 렌더러를 sj_div 무관 일괄 ÷1e6로 통일 → 원/백만 혼재 소멸 → B의 스케일 거짓경보 원천 제거.
  2. 또는 9렌즈 프롬프트 §G(부호·스케일)에 "dump는 abs<1,000,000원 행을 원-단위로 표시하니 큰 숫자라도 백만 환산 전 원값일 수 있음" 주의 1줄 추가.
- **§9 주의 반영**: B의 "신규 P1" 6건 중 4건을 duckdb로 재현 검증 → 전부 표시 artifact 오독(거짓), 2건(발행사채·영업창출현금 계열)만 실재. B 결과를 곧이곧대로 P1로 수용하면 안 되고, 스케일류는 원값 확인이 필수.
