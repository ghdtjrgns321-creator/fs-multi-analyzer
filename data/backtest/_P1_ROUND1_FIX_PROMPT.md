### 확정된 범위 (이번 라운드 — 매핑 동작 변경 없음, 무회귀 보장)
1. **모순 플래그**: 본문 매핑에서 id가 가리키는 canonical ≠ label이 alias 사전에 **정확히
   일치**하는 canonical이면 `mapping_status='id_label_conflict'` 부여. 매핑 결과는 id-first
   그대로 유지(T3 결정 보존). 유사 일치는 모순으로 치지 않는다(역방향 오염 방지).
2. **전수 모순 측정 리포트**: 일회성 스크립트(`data/backtest/_audit_id_label_conflict.py`)로
   수집 전체 회사를 스캔 — 모순 건수·금액 분포·패턴 분류(①폐지 개념(HTM 등) ②유동/비유동
   계열 내 차이 ③완전 이질 계정)를 집계해 md 리포트 산출. 이 숫자가 2단계 결정의 입력.

### 2단계 (별도 회차 — 측정 결과를 사용자가 보고 결정. 이번에 구현 금지)
- 후보 규칙: ⓐ폐지 개념 id → label 우선(안전) ⓑlabel 정확 alias 일치 시 label 우선
  ⓒ미해결 모순 → '기타 중요 계정' 강등+플래그. 측정 리포트 없이 선반영하지 않는다.

### 수용 기준
- 00120526/2021 해당 행에 `id_label_conflict` 플래그 확인. 플래그 외 매핑 결과는 재정규화
