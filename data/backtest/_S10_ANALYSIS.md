# S10 세부 분석 — report(정기보고서 주요정보) · event(주요사항보고서)

> 2026-06-15. 잣대: 분식 변별이 아니라 **"DART에 있는 유용정보를 끄집어내는가"**. S10은 두 갈래다.
> ① report = 정기보고서 주요정보 28종(구조화). ② event = 주요사항보고서 36종(시점 있는 결정).
> 둘은 성격이 완전히 다르므로 따로 판정한다. 모두 구조화 JSON 반환(문서 fetch 아님 = 가벼움).

## ① report (정기보고서 주요정보) — 28종

`OpenDartReader.report(corp, key_word, year)` → 사업보고서 안의 항목을 **구조화 테이블**로 반환.
28종: 증자·배당·자기주식·최대주주·최대주주변동·소액주주·임원·직원·임원개인보수·타법인출자·
회사채/단기사채/기업어음/신종자본증권/조건부자본증권 미상환·채무증권발행·공모/사모자금사용·
회계감사·감사용역·사외이사·주식총수 등.

| 항목 | 효익 | 우리 원문/재무제표와 |
|------|------|---------------------|
| 증자·배당·자기주식·타법인출자 | 구조화 편의 | **중복**(재무제표·SCE·주석에 있음) |
| 최대주주·소액주주·임원·직원 | 구조화 편의 | **중복**(원문 PART VII·VIII) |
| 회계감사·감사용역·사외이사 | 구조화 편의 | **중복**(원문 PART V·VI) |
| ★최대주주변동·미상환사채(트랜치별)·개인별보수·자금사용 | 구조화 + 일부 신규 | 부분 신규(narrative보다 granular) |

- **효익**: 대부분 우리가 이미 원문/재무제표로 가진 내용을 **깨끗한 구조화로** 주는 것(파싱 0).
  내용 신규성은 낮다. 소수(최대주주변동·미상환사채 트랜치·개인별보수)만 narrative보다 granular.
- **비용**: 28 key_word × 회사 × **연도**(정기보고서라 연도별). 구조화 JSON이라 가벼움.
- **필요성**: **낮음**. 같은 내용을 원문/XBRL로 이미 추출. "더 깨끗한 형식"이 주 가치이지 새 정보 아님.

## ② event (주요사항보고서) — 36종

`OpenDartReader.event(corp, key_word, start, end)` → **시점 있는 결정 공시 + 조건**을 구조화로.
36종: 유상/무상증자·감자·전환사채발행·신주인수권부사채발행·교환사채발행·조건부자본증권발행·
자기주식취득(신탁)·자기주식처분·영업양수도·자산양수도·타법인증권양수도·유형자산양수도·
회사합병·회사분할(합병)·주식교환·사채권양수도·부도발생·영업정지·회생절차·관리절차·해산·소송·해외상장(폐지).

**실호출 예 — 전환사채발행(바이오 00560982)** 반환 필드:
```
bddd(이사회결정일) · bd_fta(발행총액) · cv_prc(전환가액) · cv_rt(전환비율) ·
cvisstk_cnt(전환가능주식수) · cvrqpd_bgd/edd(전환청구기간) ·
act_mktprcfl_cvprc_lwtrsprc(리픽싱 최저조정가) · fdpp_op/fdpp_ocsa/fdpp_dtrp(자금용도: 운영/타법인취득/채무상환)
```
→ **연차 주석엔 "미상환 잔액"만 있고, 발행 시점·전환가·리픽싱 하한·자금용도는 없다.** event가 그 신규 정보.

| event 군 | 주는 신규 정보 |
|----------|----------------|
| 자본조달(유증·감자·CB·BW·교환사채) | 결정일·규모·전환가·리픽싱·**자금용도** — 희석/차입 압박 맥락 |
| distress(부도·영업정지·회생·관리절차·해산) | 위기 사건 **시점** — 연차 narrative엔 깔끔히 없음 |
| 구조조정(합병·분할·영업/자산 양수도·주식교환) | 상대·금액·조건·시점 |
| 자기주식(취득·처분·신탁) | 매입/처분 **시점·규모** |

- **효익**: **높음** — 원문에 없는 새 차원(시점 + 조건). LLM이 "언제 무슨 조건으로" 자본거래·위기·
  구조조정이 일어났는지 timeline으로 받는다.
- **비용**: 36 key_word × 회사(date-range). 회사당 비어있지않은 유형 **1~5개·총 1~12건**(실측:
  바이오 3유형/3건, 두산 5유형/12건, 소형 1유형/1건). 구조화 JSON·대부분 빈 응답이라 가벼움.
  36콜/회사 ≈ 3.5초(단일). corpus ~1,667사 ≈ 58k콜(동시 수행 시 수십 분). 저장 작음(회사당 수~수십 행).
- **필요성**: **높음** — "DART 유용정보 완전 추출" 목표에서 **가장 큰 미추출 차원**. 원문은 연차 요약만,
  event는 실시간 결정+조건.

## 종합 판정

| 갈래 | 효익 | 비용 | 필요성 | 권고 |
|------|------|------|--------|------|
| **report 28종** | 구조화 편의(내용 대부분 중복) | 28콜×회사×연도, 가벼움 | **낮음** | 보류 — 소수 신규항목(최대주주변동·미상환사채·개인별보수)만 선택 보강 |
| **event 36종** | **시점+조건(신규)** | 36콜×회사, 가벼움(대부분 empty) | **높음** | **수집 권장** — 고가치 유형 선별 시 절반 |

- **event가 S10의 진짜 가치**다. report는 "이미 있는 걸 더 깨끗하게"라 우선순위 낮다.
- event도 36종 전부보다 **고가치 ~15종**(자본조달·distress·구조조정·자기주식)으로 선별하면 비용 절반·노이즈↓.
- 용도: Phase2 LLM 컨텍스트 + 화면 timeline. "이 회사 2021-07 CB 발행(전환가 X·리픽싱 70%·운영자금)"
  같은 사실을 사실 그대로 제공(분식 확정 아님, 맥락 제공).
